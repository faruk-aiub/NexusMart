# NexusMart Backend

NexusMart is a full-stack e-commerce project backend built with NestJS, TypeScript, PostgreSQL and TypeORM.

## Features

- User registration and login
- Password hashing using bcryptjs
- JWT authentication
- Role-based access control for Admin and Customer
- Category CRUD
- Product CRUD
- Product image upload using Multer
- Cart and CartItem management
- Order and OrderItem management
- Customer order history
- Admin order status update
- Email notification trigger for order confirmation
- Email notification trigger for order status update
- Swagger API documentation

## Technology Stack

- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- JWT
- Passport
- bcryptjs
- Multer
- Nodemailer
- Swagger
